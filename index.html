ABOUT THIS WEBSITE

In high school I ran the stock trading club with two other friends. We ran a paper-traded portfolio with around 40 people through the Interactive Brokers platform, and this website accompanied that portfolio as the club's site. When my friends and I left high school, the club closed.

This past summer I started updating the website as a passion project. I developed more advanced accounting skills and learned the framework behind DCF valuations, along with Claude-based JavaScript and HTML. This website has ultimately become a way for me to continue the enjoyment I felt from the club as well as for my practice.

MOST RECENT UPDATES

  • An automatic DCF builder that takes any .htm filing from the SEC EDGAR database and produces a valuation for the company, with some additional guidance and plugins.
  • A news channel for the holdings.
  • Live price updating across the whole website, which serves as the basis for every live calculation on it. This was done using the Finnhub API service.
